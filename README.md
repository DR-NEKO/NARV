# NARV

面向西工大学生的知识刊物：公开阅读，文字与少量图片，经审稿后由作者决定发表。Notion 风格与 F 型布局，橙色主题、中文衬线标题和原创徽记。

## 当前状态

已完成本地演示，以及可部署的 GitHub OAuth + Cloudflare Worker/D1 后端实现。前端已通过 API 与本机 SQLite 完成联调。**远程 D1 已迁移，Worker API 已部署；前台已发布到 https://dr-neko.github.io/NARV/；GitHub OAuth 已配置并验证跳转，真实 OAuth 交换已走通，首个账号、唯一 Original Editor 和有效登录会话已在数据库确认。**

- 默认 4173 使用演示账号和浏览器本地数据。
- 真实模式使用 API 会话、服务端权限与数据库；不显示演示账号切换。
- 本地演示数据不会自动进入线上。
- 自动暂存仍保留在当前设备；真实模式点击“暂存草稿”会写入服务器。
- 上线前还有免费额度与实际负载验收、隐私和纠错渠道等事项；首轮业务备份与本地恢复演练已完成。

完整进度见 [产品路线图](ROADMAP.md)，资源配置见 [部署步骤](docs/deployment.md)。

## 使用

Node.js 22.13 或更新版本：

```sh
npm ci
npm test
npm run dev
npm run dev:api
npm run backup
npm run build
```

4173 为原有本地演示；4174 为 Worker 逻辑与本机 SQLite 的联调页面，未配置 OAuth 时不能真实登录。KaTeX 和字体连同许可证本地托管，运行时不依赖外部 CDN。

设置 NARV_API_URL 后构建真实模式；不设置则构建演示模式。GitHub Pages 工作流读取同名仓库变量。

## 已有功能

- 公开文章、专题、全文搜索；标题、正文和已审核评论匹配，时间／栏目／作者筛选、关键词组合、少量错字容忍。
- Markdown 子集与 LaTeX 数学公式；短引用图片、粘贴／拖放／压缩／移除；草稿和版本独立保存附件。
- “我的投稿”“已发表帖子”“我的评论”“我的收藏”；评论状态筛选、退回理由、修改重提、撤回与审核记录；收藏排序和取消。
- 六级权限、公共审稿队列、领取、回避、审稿决定、上诉、修改／撤回申请；权限降级会释放不再符合条件的任务。
- 首份意见后锁定；退修草稿单独保存，正式提交后才成为下一审阅版本。
- 一名合格审稿人通过即可录用，发表权归作者；立即发表、定时发表、取消定时与公开撤稿说明。
- 每次投稿必须确认内容责任和投稿须知；可选公开邮箱需另行确认。
- 审稿人申请、独立多人认可、转正与逐级晋升；质量和上诉标签仅辅助人工判断。
- 双身份昵称与头像；Editor 以上查询对应关系需理由、留痕和通知。公开接口剔除内部身份信息，审稿接口使用稿件专用作者标识。
- 收藏、互斥赞踩、审核后的中长评论、个人通知与公开／内部公告。
- 后端 GitHub OAuth、双段 PKCE、单次登录交换、哈希会话存储、CORS、事务并发控制、限流和后台发表任务。

## 验证与边界

行为测试和浏览器验收见 [验证记录](docs/validation.md)。搜索是关键词和模糊匹配，不是语义搜索。双身份降低直接关联风险，不保证匿名。

后端目前是**有容量硬限制的试运行实现**，整体读取再裁剪数据；尚不适合大规模开放。默认 100 账号、每账号 50 稿件、全站业务数据 8 MB，达到上限明确失败，不自动购买额度。线上部署必须继续保持免费计划，并完成实际 CPU／配额验收。

## 文件

- public/：前端、纯业务规则、本地适配器与 API 客户端。
- backend/：Worker、OAuth、权限裁剪、D1 存储和迁移。
- tests/：纯规则、数据隔离、OAuth 与数据库行为测试。
- scripts/browser-check.cjs：完整演示流程。
- scripts/backend-browser-check.cjs：独立临时数据库与浏览器的 API 联调。
- scripts/image-check.cjs：图片编辑、版本和发表验证。
- docs/logo-prompt.md：生成徽记的设计提示词；public/assets/narv-emblem.png 为当前素材。

不将真实密钥、.dev.vars、.local 数据库、浏览器测试截图或 node_modules 提交到公开仓库。生产构建只复制 public/。
