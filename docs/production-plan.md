# 正式服务接入进度

更新：2026-09-28。实现已经从纯本地原型推进到前后端联调，尚未部署线上。实际配置顺序见 [部署说明](deployment.md)。

## 已落实

GitHub Pages 托管前端；Worker 处理 GitHub OAuth、会话与业务权限；D1 保存账号、稿件、版本、压缩图片、审稿、申请、互动、通知和审计。公开数据按白名单裁剪，身份对应关系必须通过带理由的受限操作查询。后台 cron 每分钟检查作者设定的发表计划。

前端保留演示与 API 两个适配器。所有线上状态转换使用服务端账号权限，客户端传入角色无效。D1 事务和修订号处理并发覆盖；本地 SQLite 适配器验证相同查询与业务逻辑。

## 部署依赖

用户目前只有 GitHub 账号；还需要本人注册 Cloudflare 免费账号、完成 CLI 授权、创建 D1 与 GitHub OAuth App。仓库和站点均未发布。GitHub 原始身份只用于核验登录，不自动公开昵称、头像或邮箱。

Secret 只能保存在 Worker Secret 或本地未跟踪的开发配置中，不应出现在聊天或仓库。

## 开放征稿前仍需完成

- 真实 GitHub 授权和 HTTPS 回调验收，最高编辑身份、退出与会话失效。

当前后端有硬性试运行上限，见 deployment.md。不能把局部联调通过等同于已经上线或不受容量限制。
