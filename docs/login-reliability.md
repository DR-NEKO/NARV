# 登录与账号资料刷新

2026-09-29

## 本轮原因与修复

原会话只存 sessionStorage，关闭标签页即丢失；服务端会话仅 12 小时。新版本使用持久存储保存令牌与到期时间；会话 30 天，读取本人资料时按天续期，旧的有效会话可平滑续期，已失效／退出／注销的会话不恢复。退出清理两处令牌、个人缓存、联系草稿；其他标签页同步退出。私密后台正文不保存在持久摘要中。

原登录回执 60 秒有效、交换前删除、前端提前清理 URL 与 PKCE 校验信息。新回执 10 分钟有效，校验通过后原子建立且仅建立一份会话；交换凭据绑定 PKCE，网络丢失响应时可重试返回相同会话。数据库只保存令牌哈希，不保存明文会话／GitHub access token。退出后的回执不能重新建立会话。URL 与当前校验信息只在成功后删除，失败保留重试入口。

GitHub 授权过程每次使用独立绑定 cookie 和前端校验记录，避免多个登录流程互相覆盖。OAuth code 交换不自动重复；只对 GitHub 用户资料 GET 的临时失败作有界重试。超时／回调错误返回站内登录页，保留可理解的错误提示。

交换响应直接带本人资料；账号立即出现，工作台队列单独加载。本人资料请求按会话去重。只对 GET 与可幂等的登录交换作有界重试，普通业务写入不会因自动重试重复提交。

账号列表按固定账号主键／persona UID 关联，每次进入后台重新读取最新名字；默认明确标记审稿身份。社区昵称与审稿昵称独立，改一侧不会替换另一侧。社区查询仍需 Editor+ 权限、理由与审计，不把两套身份公开关联。

## 验收与边界

74 项自动测试通过，包括 OAuth cookie/双段 PKCE、错误校验不耗尽有效回执、并发交换唯一会话、失去响应重放、退出不可重放、30 天会话与旧会话续期、持久存储迁移及过期清理。

scripts/auth-browser-check.cjs 使用隔离 SQLite 和真实浏览器：首次交换写入后丢失响应自动重试、无需串行 /me 即显示账号、队列延迟不阻塞登录、同浏览器新标签页／新浏览器上下文恢复、跨标签页退出、改名后立即重新进入列表与详情显示当前昵称，UID 不变。

GitHub 官方实际授权需真实用户完成；不伪造生产会话验证。网络到 GitHub／Cloudflare 的连通性仍可能影响耗时，有界重试不能保证任意网络下即时响应。浏览器清理站点数据、无痕窗口结束或服务端会话撤销仍需重新授权。
