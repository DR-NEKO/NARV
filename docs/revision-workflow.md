# 返修、逐条回复与阅读页

审稿总意见和原文批注没有字数下限，可留空。总意见最多 5000 字，单条批注最多 2000 字；审稿决定、版本核验、利益冲突确认仍是必填。快捷模板填入可编辑文本，不会自动提交决定。

未保存批注可直接定位原文，取消不生成任何持久记录。批注仍按提交版本、段落、文本偏移绑定。跨版本定位打开原版本，不能移到不对应的新文字。

作者可以分别回复一份审稿的总意见和每条批注。保存的回复草稿仅作者可见；下一次提交修订稿时，回复一并冻结并标明提交版本。提交之后不能篡改历史回复，下一轮可以增加新的回应。回复和批注都不进入公开文章、目录、搜索索引或作者主页。

返修编辑左侧读取最近的不可变提交版本；右侧默认从它开始，已保存的工作草稿和同版本本机暂存优先恢复。写作模式逐字高亮新增和删除；预览模式高亮修改段落，保留 Markdown、公式、图片与代码语法。二次及以后审稿读取上一提交版本与当前提交版本，使用同样的预览差异。移动端两栏纵向排列。上一版读取失败显示重试，不伪造基准版本。

差异计算使用自托管 [jsdiff](https://github.com/kpdecker/jsdiff) 8.0.2。行差异设 20 ms 与 2000 编辑长度上限；短修改区块在总预算内做逐字差异。大规模重写超出预算时退为整体改动标记，避免输入长时间阻塞；输入后 180 ms 合并更新。预览标记是展示环境参数，不修改稿件源文，不写入公开数据。

发表页仅在开头一级标题与文章标题相同、作者栏与发表署名相同时合并重复内容。异名标题、正文里的“作者”文字不会删除。原稿、历史版本、导出内容保持原样。

发表页采用头像＋作者名、摘要、日期与阅读时长的层次，UID 放在作者主页。目录按实际 Markdown 层级建立树，默认折叠子层级，颜色与分隔线帮助辨认；展开箭头不改变页面路由。公开作者主页以所选署名 UID 聚合公开文章，资料来自最近公开署名，未查询账号绑定、权限或另一身份。

验证：90 项单元测试，以及隔离数据库中的批注、回复、修订、再审、发表、作者主页和移动布局浏览器验收。未操作真实用户稿件。

后续完善方向：作者主页的公开资料独立维护；更多元数据（标题、摘要、配图）差异摘要；作者回复本机自动暂存与未保存离开提醒。当前逐条回复需点击保存，并在修订提交前检查未保存回复。
