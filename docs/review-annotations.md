# 审稿批注与内容权限

2026-09-29

## 撤回与删除

无审稿意见、从未发表的主动撤回稿件只允许作者访问，包括正文、历史版本和导出。当前／历史认领者、AE、Editor、OE 都没有这一阶段的内容特权。新撤回释放认领关系，记录仅供作者定位曾经的审稿安排；旧记录即使仍带 reviewerId，也按同一权限规则拒绝。

已彻底删除的稿件、版本、附件引用和相关通知从业务数据移除，所有账号请求正文或版本都返回不存在。永久下架的审核记录仍遵循既有复核制度，与作者删除未审稿件是不同操作。

工作台按同一 canView 规则过滤；消息查询拒绝失效私密稿件链接。迁移 0005 清理历史撤回与已删除稿件的失效通知，保留作者自己的撤回通知与仍可访问稿件的通知，不删除正文。

前端每次打开详情／修改页面都重新验权，核验前不展示旧详情；403／404 清理该稿件缓存、列表、通知、编写暂存和批注窗口。GET 响应绑定权限代次，晚到的旧读取不能重新填回已清除的数据。导出同样验权。

公开阅读没有新增轮询。仅登录后的私密稿件页面在前台每 30 秒检查轻量访问状态，切换窗口重新检查；隐藏的稿件详情先遮蔽正文，返回时检查通过才恢复。撤回在接口层立即生效；已打开页面需要等待下一次检测及网络返回，不声称能收回用户此前下载或复制的内容。

## 批注

审稿人可在格式化正文选中同一段内 1–1000 字，或使用段落旁的“＋”批注整段。支持标题、段落、列表、代码、公式整段、表格单元格。批注文本 5–2000 字，每轮最多 50 条，每稿草稿与已发送批注总计最多 200 条。

定位使用稿件版本、审稿轮次、Markdown 段落标识、规范化原文字串的起止位置及前后文；位置采用 UTF-16 字串索引，与屏幕行号、分页、字体和视口宽度无关。服务器重新解析该版本并核对原文，拒绝伪造引用、越界或截断表情。多处相同文字靠片段起止位置区分。

批注草稿保存在真实后端，只有保存它的审稿人在仍具备稿件访问权时可见，可修改或删除。作者及其他权限账号不能通过详情、工作台或实体摘要读取它。草稿不发通知，不加积分，也不算已经给出的审稿意见，作者仍可以撤回未收到意见的稿件。

提交正式审稿决定时，服务器将本版本／本轮批注复制到不可变审稿记录，作者此时可读取；只有本轮批注一起发送。未保存的批注编辑会阻止提交，避免遗漏。旧版／旧轮草稿不会静默套到新版。

作者和有权限的审稿人可点击“定位原文”。如果正文已修订，会请求批注绑定的原提交版本，并在独立窗口中定位。只高亮原来的段落，不用模糊匹配把意见自动移动到新的相似文字。版本接口同样遵守撤回与删除权限，撤权时关闭窗口。

存储沿用压缩稿件记录与容量保护，不增加服务器、收费服务或外部评论系统。批注不进入公开文章、公开搜索或静态导出。

## 验证

85 项自动测试，包括：全部角色的撤回权限、旧认领绕过拒绝、删除后的版本拒绝、批注所有权、持久化、草稿私密性、源文字／版本校验、表格与表情边界、随决定发送、历史通知迁移。

真实 SQLite 与浏览器验证：原审稿人、AE、另一作者标签页撤权后清缓存；格式化文字和公式批注保存、刷新、修改；作者只能看到正式发送的批注；修订后原版本窗口定位；手机无横向溢出。原投稿、审稿、收藏、评论、头像、账号管理、消息缓存回归通过。
