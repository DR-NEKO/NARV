# 私密联系与反馈

日期：2026-09-29。所有反馈必须通过真实账号登录提交，遵照用户确认的要求；不提供匿名提交、公开反馈列表、公开处理进度或普通用户的反馈历史页。

## 入口与类别

前台入口：页脚“联系我们”，地址 #/contact。已发表文章可“联系编辑”；自己的稿件审稿记录下可“向编辑反馈审稿问题”，带入稿件编号。

五类：Bug 反馈、功能建议、举报用户、举报审稿人、其他反馈。支持标题、详细说明、证据／日志／链接、相关稿件编号、可选联系邮箱和页面地址；可以选择社区或独立身份署名。反馈只记录选定身份的提交时昵称和固定 UID，不自动复制 GitHub 昵称、邮箱、登录绑定或其他身份。

提交成功只返回收件编号和接收时间，不返回存储正文或内部处理记录。普通用户持有编号也不能读取反馈接口。

## 后台

Editor 及以上工作台增加“私密反馈”。按类型与状态筛选，50 条一页，正文按需读取，不一次下载全部证据。

支持领取、内部备注、标为完成、说明原因关闭及重新打开。处理使用版本 CAS 和账号权限依赖，防止抢占任务、过期页面覆盖记录或权限变更后继续处理。每条最多 40 次操作，内部备注 10–5000 字。

有新反馈时，对合适的编辑发送站内通知，最多通知 20 个账号并优先覆盖 OE。通知仅说明收到私密反馈，不含标题、正文、邮箱或举报当事人；通知不会发给被举报者。没有合适处理人员时，反馈保存在对应权限的队列，等待具备条件的人员处理。

举报按 C-/R-UID 定位，不根据重复昵称猜测。举报审稿人也可用自己的稿件编号定位当前审稿人，或最近一份审稿意见的审稿人；不允许借用别人的稿件窥探内部安排。涉及更早的特定审稿人时，可填写其 UID，或提供自己的稿件编号及对应版本／轮次。自己的稿件历史意见下也可直接带入版本与轮次。

## 权限与回避

- 普通用户、临时 Reviewer、常驻 Reviewer、AE 和未登录访客不能读取后台列表或正文；连提交者本人也不开放反馈历史或内部处理结果。
- Bug、建议和其他反馈由有效 Editor／OE 查看处理。
- 用户或审稿人举报由 Editor 及以上、达到相应权限的处理人员查看；涉及 Editor 的举报只交 OE。
- 被举报账号不能查看或处理自己涉及的反馈；拥有管理角色的举报者也回避自己的举报。
- 唯一 OE 无更高等级，涉及 OE 的举报交其他 Editor 独立处理，OE 账号不能通过站内接口读取该反馈。处理反馈不会赋予 Editor 对 OE 封禁、降级等越级权限。
- 封禁中的账号仍可以反馈，便于申诉或说明；封禁中的编辑不能管理队列。
- 这些是站内接口的权限边界，不声称数据库运营者无法通过其 Cloudflare 管理权限访问数据库。

管理 DTO 不输出提交者或目标的内部账号主键、GitHub 绑定、另一套身份；不自动生成跨身份资料链接。处理人以独立昵称显示，历史保留当时署名；固定主键用于后台关联，改昵称不改变案件归属。

## 私密性与删除

独立 feedback 表只被私密接口读取，不加入 DomainStore 的普通 bootstrap，不进入 public_documents、文章／评论、搜索块或 Pages 导出。接口使用 no-store。

后台正文和证据按纯文本转义展示，不执行 HTML，也不加载证据里的外部图片或脚本。可选邮箱仅后台可见；不会自动发送邮件，人工回复可使用用户自愿提供的联系方式。

自己的反馈在浏览器会话中暂存，失败保留输入；提交成功及退出登录清理。后台反馈与审稿信息不写进普通用户的会话摘要。

永久注销立即删除该账号提交的反馈及针对该账号的反馈。其他反馈中作为处理人的关联由持久清理队列解除；未完成任务重新回队列，历史处理昵称匿名化。清理按结构化账号引用匹配，不用子串匹配，否则相似账号 ID 会使任务无法完成。

业务备份包含私密反馈表，仍只写到本机受限的 .local/backups，不能上传到公开仓库。旧备份保留／恢复前重放删除规则仍是 ROADMAP 的后续事项。

## 资源与可靠性

- 每个账号每天最多 5 条，以上海自然日计算；配合现有写接口分钟限流。
- 标题 5–100 字，正文 20–10000 字，补充证据最多 4000 字；本轮不增加附件存储服务。
- 请求 UUID + 内容指纹实现创建幂等。网络丢失响应后，同一内容重试返回原编号，不重复入库或通知；同一请求键换内容会拒绝。
- 案件、站内通知和每日额度检查放在同一事务；额度与容量失败不会留下半张工单。
- 存储计入现有容量保护，反馈备注更新也有同事务容量检查，保留零付费部署约束。估算业务字节不是 SQLite 文件真实尺寸。

## 验收

9 项新自动测试，加原有测试共 74 项通过。覆盖全部登录要求、本人／AE／访客读取拒绝、反馈正文不进入公开数据或普通工作台、通知不含秘密、Editor／OE 回避、稳定 UID 与本人稿件定位、并发领取及修改冲突、重复请求与并发日限额、筛选分页、封禁账号反馈、注销删除与历史匿名化。

真实 SQLite + 浏览器验证：登录返回联系页面；提交失败保留输入；模拟服务器已写入但响应丢失后重试只留一个案件；正文 HTML 不执行；普通用户不见正文／处理结果；被举报 Editor 被拒绝而 OE 可查看；移动端无横向溢出；退出清除联系草稿。
