# Markdown 阅读与投稿模板

2026-09-29

文章、投稿预览、审稿正文、回应共用自托管 markdown-it 15.0.2，替换按空行切块的简易解析。支持六级标题、段落边界、Markdown 横线、粗体／斜体、引用、有序与嵌套列表、表格、代码块。正文标题与目录用同一份解析结果，不把代码块里的 # 误当目录。

一级标题使用主题色、2px 深橙下划线；二级使用 1px 浅橙线；三级在第一行最左侧显示 3px 宽的主题色短竖线。正文保留系统阅读字体，标题保留衬线字体。独立 ---、***、___ 渲染横线。遵循标准 Markdown：紧贴文字下方的 --- 会作为 Setext 二级标题；需要分隔线时在前面留空行。窄屏表格与代码在自身容器横向滚动。

原有 LaTeX 语法继续支持：$...$、$$...$$、\( ... \)、\[ ... \]。代码中的公式或横线保持字面内容，转义美元符号不触发数学渲染。KaTeX 继续按需加载，限制展开并关闭信任命令。原始 HTML 禁用，Markdown 默认协议检查与图片白名单保留；图片短标记继续解析成附件或缺失提示。解析器及所有打包依赖许可证保存在 public/vendor/markdown-it；重建运行 node scripts/vendor-markdown.mjs，不依赖外部 CDN。

新投稿默认预填一级标题、作者栏、章节结构和写作提示。上方标题与选定身份更新时，同步尚未被手改的模板标题／作者行。署名只填选择的站内身份；切换到独立身份时不保留自动填入的社区名字。已存本机或服务端草稿不重填，能识别原模板署名并跟随身份切换；手写的正文标题不会因更改稿件标题被覆盖。

同步调整删除规则：从未提交的草稿仍可删除；已提交甚至被认领的稿件，作者主动撤回且从未收到任何审稿意见也可删除。已有意见、公开记录、举报处置的稿件不能借此入口删除。服务端检查所有权与稿件记录版本，原子清除稿件／提交版本、附件引用和相关通知，不直接操作用户的真实线上稿件。

79 项自动测试通过；新增解析安全、公式／代码边界、目录、模板切换及已认领无意见稿删除与清理测试。scripts/markdown-browser-check.cjs 验证实际文章、投稿预览、深浅分隔线与短竖线、手机布局、模板身份切换、草稿恢复与删除权限。
