# 刷新、交互与界面调整 · 2026-09-28

用户要求：刷新／工作台切换／操作提醒提速；搜索控件重做；浏览器标题只显示 NARV；删掉宣传口号、页脚定位和整个“名字与视觉”说明；每篇最多 10 张图片；作者可以删除从未提交的草稿。

## 已实施

- 直接使用 TanStack Query Core 5.104.0（MIT）处理工作台查询缓存、请求去重、预取和失效。源码预览用已打包 vendor，正式构建由 esbuild 0.28.1 合并并生成哈希文件名；依赖固定版本且保留 LICENSE。
- 页面框架先显示，不再等账号和业务数据全部回来。字体 CSS 不阻塞首屏，KaTeX 仅在出现数学公式时加载。
- “我的投稿”与“已发表帖子”共享基础数据；双身份设置使用已有账号资料，不请求工作台业务。其他页按需读取；通知／公告不再随所有子页重复查询。
- D1 记录、版本和全局修订号一次 batch 原子读取；页面独立查询合并为批次。无图片头像的普通积分页面业务读取只需 3 次数据库往返（含头像时另有一次附件查询，不含 Worker 会话校验）。
- 已访问页面 60 秒内直接显示；悬停或键盘聚焦时按需预取。刷新只短暂保留本标签页自己的账号和稿件摘要，最长 60 秒并重新验证会话；不持久化他人队列、关联查询或草稿正文，退出／401／身份变更清理。
- 写成功后返回紧凑结果、当前用户资料、计数和真实提交修订号；立即更新当前视图／成功提醒，后续读取在后台进行。拒绝旧响应回滚新状态，删除草稿后迟到的读取也不能重新插入它。
- 草稿删除仅限作者、状态 draft、版本 0、无提交版本／审稿／确认记录。删除实体和附件引用；未使用图片块按原垃圾清理周期回收。提交后即使撤回，也不能走这个删除接口。
- 10 图上限同时在编辑器和服务端实施；新图自动压缩到约 120 KB 的数据引用，总图片数据 1.2 MB 内，保持 1.6 MB 请求上限。正文仍使用短标记，图片和历史版本不重复传回写确认。
- 搜索输入／按钮 48 px（手机 44 px），筛选控件 42 px，日期成组、作者栏手机通栏；保留日期、范围、栏目、作者、AND/OR、排序和错字容忍。
- 标题始终 NARV。页脚只保留名称和功能链接；去掉首页悬空按钮，投稿入口保留在导航。关于页不含“名字与视觉”或其解释。
